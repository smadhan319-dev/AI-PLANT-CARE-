# AI PLANT CARE
1. Unzip the folder.
2. Open index.html in Chrome, Edge, Safari or Firefox (works offline for Library and Tips).
3. For photo diagnosis and Ask: open Settings, paste your Google Gemini API key (aistudio.google.com/apikey), tap Save.
Tip: to use it on a phone, upload the folder to any free static host (Netlify, GitHub Pages).
Note: the key is stored only in your browser. Do not share the app publicly with your key inside it.

Features: AI photo diagnosis, My crops tracker, Weather and spray advice (needs internet and location), Disease library, Community Q&A, Ask AI, Fertiliser and spray calculators, 8 answer languages.
